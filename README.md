# 🌐 Portfolio Deployment

This project also demonstrates the deployment of a React/Vite application using **GitHub Actions and GitHub Pages**.

### Deployment Flow

```text
Developer
    │
    ▼
GitHub Repository
    │
    │ Push to main
    ▼
GitHub Actions
    │
    ├── Checkout Source
    ├── Setup Node.js
    ├── Install Dependencies
    ├── Build React/Vite Application
    ├── Upload Build Artifact
    └── Deploy to GitHub Pages
    │
    ▼
GitHub Pages
    │
    ▼
Live Portfolio
```

## 🚀 Run Locally
Clone the repository:
```text
git clone https://github.com/VeeraBabu-Devops/portfolio-deployment-using-github-actions.git
```
Navigate to the project:
```text
cd portfolio-deployment-using-github-actions
```
Install dependencies:
```text
npm install
```
Start the development server:
```text
npm run dev
```
Build for production:
```text
npm run build
```

## 🔄 Deployment
Deployment is automated using GitHub Actions.
Every push to the ``` main ``` branch triggers the deployment workflow.
```text
git add .
git commit -m "Update portfolio"
git push origin main
```
GitHub Actions automatically builds and deploys the latest version to GitHub Pages.
